    User Roles & Permissions¶

    Overview¶

    Ntech Paystack implements a role-based access control system with two primary user types:

    1. Admin User
    2. Full access to configure Paystack settings
    3. Can generate all types of payment flows
    4. Access to webhook management

    5. View all payment requests

    6. Payments User

    7. Limited access to generate payments only
    8. Can view their own payment requests
    9. No access to settings or configuration

    Role Configuration¶

    Admin User Role¶

    Permissions: - Paystack Settings: Read, Write, Create, Delete - Payment Request: Read, Write, Create - Payment Entry: Read - Webhook Log: Read - System Settings: Read, Write

    Payments User Role¶

    Permissions: - Payment Request: Read, Write, Create (own records only) - Payment Entry: Read (own records only) - Webhook Log: Read (own records only)

    Role Assignment¶

    1. Go to: Settings > Role Permission Manager

    2. Create or edit roles: 

      # Example role creation
frappe.get_doc({
    "doctype": "Role",
    "role_name": "Paystack Admin",
    "desk_access": 1
}).insert()

    3. Assign permissions: 

      # Example permission assignment
frappe.get_doc({
    "doctype": "DocPerm",
    "role": "Paystack Admin",
    "parent": "Paystack Settings",
    "read": 1,
    "write": 1,
    "create": 1,
    "delete": 1
}).insert()

    Role-Based Features¶

    Admin User Features¶

    1. Configuration Management
    2. Set up Paystack API keys
    3. Configure webhook settings
    4. Manage IP whitelisting

    5. Set up payment gateway options

    6. System Monitoring

    7. View all payment requests
    8. Monitor webhook logs
    9. Track payment statuses

    10. View payment history

    11. Security Management

    12. Configure IP restrictions
    13. Set up signature verification
    14. Manage user access levels
    15. Monitor failed attempts

    Payments User Features¶

    1. Payment Generation
    2. Create payment requests
    3. View own payment status
    4. Generate payment links

    5. Track own payment history

    6. Payment Management

    7. Cancel own payment requests
    8. View payment details
    9. Track payment status
    10. Get payment receipts

    Best Practices¶

    1. Role Assignment
    2. Assign Admin role only to trusted users
    3. Regularly review user permissions
    4. Document access levels

    5. Monitor user activity

    6. Security

    7. Never share API keys
    8. Use strong passwords
    9. Regularly audit permissions

    10. Monitor failed login attempts

    11. Monitoring

    12. Track payment request patterns
    13. Monitor webhook performance
    14. Watch for unusual activity
    15. Regularly review logs

    Troubleshooting¶

    Common Issues¶

    1. Access Denied
    2. Solution: Verify role permissions

    3. Check: Role Permission Manager

    4. Missing Features

    5. Solution: Review role configuration

    6. Check: User permissions

    7. Security Alerts

    8. Solution: Review access logs
    9. Check: User activity history

    Verification Steps¶

    1. Check user roles: 

      frappe.get_roles()

    2. Verify permissions: 

      frappe.has_permission("doctype", "read")

    3. Monitor activity: 

      frappe.get_all("Activity Log", filters={"user": "user@example.com"})
